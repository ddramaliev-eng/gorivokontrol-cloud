# GorivoKontrol Cloud

Уеб версия на GorivoKontrol (следене на зареждания с гориво за автопарк),
пренесена от desktop (Tkinter) v2.3 във Flask, за да може да се хоства в
облак по същия начин, както DramaBus Cloud.

## Локално стартиране (за тест)

```bash
pip install -r requirements.txt
APP_PASSWORD=избери-парола SECRET_KEY=произволен-низ python3 server.py
```

Приложението стартира на `http://localhost:5000` (или на порта от `PORT`).

## Деплой в Railway (същите стъпки като DramaBus Cloud)

1. **GitHub** — качи тази папка в ново GitHub хранилище:
   ```bash
   git init
   git add .
   git commit -m "GorivoKontrol Cloud - начална версия"
   git branch -M main
   git remote add origin <URL на твоето GitHub хранилище>
   git push -u origin main
   ```

2. **Railway** — влез с GitHub акаунта → „Нов проект“ → „Внедряване от GitHub repo“ →
   избери хранилището. Railway ще разпознае Python проекта чрез `requirements.txt`.

3. **Procfile** — вече е включен: `web: gunicorn server:app --bind 0.0.0.0:$PORT`
   (еквивалент на `uvicorn server:app` при FastAPI, само че за Flask).

4. **Променливи на средата** (Settings → Variables), задължително:
   - `APP_PASSWORD` — паролата, с която ще влизате в приложението.
   - `SECRET_KEY` — произволен дълъг случаен низ (напр. `openssl rand -hex 32`),
     за подписване на login сесиите.
   - `DATA_DIR` — задай `/app/data` (виж следваща стъпка).

5. **Том (Volume)** — задължително, иначе базата `data.db` ще се трие при всеки
   redeploy: десен клик върху canvas-а → „Volume“ → mount path `/app/data`
   (същия път като `DATA_DIR` по-горе).

6. **Публичен домейн** — Settings → Networking → „Generate Domain“, ще получиш
   адрес от типа `нещо.up.railway.app`.

## Какво прави приложението

- Автомобили и зареждания (добавяне/редакция/изтриване), със същите проверки
  като desktop версията (положителни числа, дата не в бъдещето,
  предупреждение при намаляващ километраж).
- Отчети (месечни/годишни, по автомобил/автопарк, филтър по вид гориво),
  графика (Chart.js) и обобщение — **общите суми коректно конвертират
  евро-периодите в лева** (курс 1.95583) вместо да ги сумират директно с
  лева, каквато беше грешката в оригиналния desktop код.
- Подробен изглед на всички зареждания + търсене.
- Excel износ (обобщен и подробен) - идентичен формат на desktop версията.
- Резервно копие на базата (бутон „⬇ Резервно копие“ в менюто) - изтегля
  `data.db` директно, ако някога решиш да се върнеш към desktop версията
  или просто искаш офлайн копие.
- Единична парола за достъп (`APP_PASSWORD`) - тъй като приложението ще е на
  публичен адрес, а данните за гориво/разходи на автопарка не са за пред
  всеки. Ако искаш индивидуални акаунти по-нататък (различни пароли/роли за
  различни служители), кажи - може да се добави.

## Данни от старата desktop програма

Ако искаш да пренесеш съществуващите записи от Tkinter версията (`data.db`),
качи стария `data.db` файл в Railway Volume-а (през файлов достъп/CLI на
Railway) на mount path-а `/app/data/data.db` преди първото пускане на
сървъра - схемата на таблиците е идентична, така че ще проработи директно.
